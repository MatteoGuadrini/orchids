# Orchids Theme for VS Code

A light & dark color theme for VS Code — every hue sampled from five living orchid species.

![Orchids Theme](https://img.shields.io/badge/VS%20Code-Orchids%20Theme-pink?style=for-the-badge)

## Overview

Orchids is a meticulously crafted color theme that draws its palette from the natural beauty of five orchid species:

- **Phalaenopsis** — Delicate pinks and magentas
- **Vanda** — Rich purples and violets
- **Cattleya** — Vibrant fuchsias
- **Paphiopedilum** — Earthy greens and browns
- **Oncidium** — Golden yellows and oranges

Each color in this theme is carefully sampled from these remarkable flowers, creating a harmonious and natural coding environment that's easy on the eyes throughout long coding sessions.

## Features

- **Two Variants**: Light and dark themes to suit your preference and environment
- **14 Syntax Roles**: Comprehensive syntax highlighting for all major programming languages
- **16 ANSI Colors**: Full terminal color support
- **Carefully Balanced Colors**: Optimized contrast ratios for readability
- **Natural Aesthetics**: Colors inspired by nature, not arbitrary selections

## Installation

### Via VS Code Marketplace
1. Open VS Code
2. Go to Extensions (Ctrl+Shift+X)
3. Search for "Orchids"
4. Click "Install"

### Manual Installation
1. Download the latest release from the [Releases](https://github.com/your-username/orchids-vscode/releases) page
2. Extract the downloaded zip file
3. In VS Code, go to Extensions (Ctrl+Shift+X)
4. Click the "..." menu in the Extensions view
5. Select "Install from VSIX..."
6. Navigate to the extracted folder and select the `.vsix` file

## Activation

After installation, activate the theme by:

1. Opening the Command Palette (Ctrl+Shift+P or Cmd+Shift+P)
2. Typing "Preferences: Color Theme"
3. Selecting "Orchids Dark" or "Orchids Light"

Or add this to your settings.json:

```json
{
  "workbench.colorTheme": "Orchids Dark"
}
```

## Customization

You can customize the theme further by overriding specific colors in your VS Code settings. For example:

```json
{
  "workbench.colorCustomizations": {
    "[Orchids Dark]": {
      "editor.background": "#1A1322",
      "editor.foreground": "#EFE7F6"
    }
  }
}
```
