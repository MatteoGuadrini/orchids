## [1.0.0] - 2024-01-XX

### Added
- Initial release of Orchids theme for VS Code
- Orchids Dark theme with comprehensive syntax highlighting
- Orchids Light theme with comprehensive syntax highlighting
- Support for 50+ programming languages
- Full terminal color support (16 ANSI colors)
- Optimized UI colors for editor, sidebar, status bar, and more
- 14 syntax roles for comprehensive code highlighting
- VS Code marketplace-ready package
